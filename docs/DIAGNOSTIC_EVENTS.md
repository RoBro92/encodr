# Diagnostic Events

Encodr writes structured JSONL diagnostics through `encodr_shared.diagnostics`. Events are exposed in Settings -> Diagnostics and diagnostic bundles.

## Field Contract

Every structured event should include the formatter fields:

| Field | Meaning |
| --- | --- |
| `timestamp` | UTC ISO-8601 time generated by the logging formatter. |
| `level` | `debug`, `info`, `warning`, `error`, or `critical`. |
| `component` | Logical source, usually `api`, `worker`, `worker-agent`, or `system`. |
| `logger` | Python logger name. |
| `event` | Stable searchable event name. |
| `message` | Short operator-facing summary. |
| `fields` | Structured details. |

Common detail fields:

| Field | Meaning |
| --- | --- |
| `job_id` | Job affected by the event. |
| `worker_id` / `worker_key` | Local or remote worker identity. |
| `file_id` / `tracked_file_id` | Tracked library file identity. |
| `operation_id` | Bulk queue, scan, or background operation identity. |
| `status` | Resulting state or HTTP status. |
| `reason` | Redacted human-readable reason for a warning or failure. |
| `exception_type` | Exception class for failures. |
| `errno` | OS errno when available. |
| `duration_ms` | Operation duration when measured. |

Log levels:

| Level | Use |
| --- | --- |
| `DEBUG` | Internal decision details only when useful. |
| `INFO` | Normal actions and state transitions. |
| `WARNING` | Recoverable problems, fallback paths, queue skips, or review triggers. |
| `ERROR` | Failed user-visible actions, blocked operations, ffmpeg/ffprobe failures, permission failures. |
| `CRITICAL` | Data-loss risk or unrecoverable startup/runtime failure. |

Secrets, tokens, auth headers, API keys, and DSNs with credentials are redacted by the formatter. Path redaction is applied when Settings -> Diagnostics has "Redact paths and file names" enabled, and diagnostic bundle exports default to redacted paths.

## Noise Controls

The runtime intentionally avoids per-frame/per-progress spam. Worker progress is emitted only when the progress stage changes. Bulk queue item failures are logged individually, while completion emits aggregate counts. FFmpeg command details are logged as structured metadata; stdout/stderr and exception strings pass through redaction before being written.
